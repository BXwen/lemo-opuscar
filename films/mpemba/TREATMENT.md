# TREATMENT —《姆潘巴悬案》The Mpemba File

风格：halftone-dossier（复古半调案卷）｜时长约 50 s｜1920×1080 @ 30 fps｜无配音，字幕卡+音乐驱动｜全部代码生成

---

## 1. 三个候选结构

**A. 悬案档案（正叙查案）**
整部片是一份编号卷宗 CASE 1963-MPE 的宣读：物证袋开场 → 事主陈述（1963 坦桑尼亚）→ 前科记录（亚里士多德/培根/笛卡尔）→ 1969 年复现 → 嫌疑人板（五个假说）→ 结论页被涂黑 → 盖章「未结案」→ 归档抽屉。
*优点：最贴合档案美学的「一次宣读一件物证」语法；「前科记录」把科学史变成刑侦梗，反差幽默自然生长；结论涂黑 = 科学确实无定论，形式与内容同构。*
*缺点：正叙略平，钩子必须足够狠。*

**B. 倒推审讯（从结果开始）**
开场直接给结果：热水赢了。然后像审讯一样倒查——「你有同伙吗？」逐个提审五个假说嫌疑人，每个都说不清，最后法庭宣布证据不足。
*优点：冲突感强。*
*缺点：审讯框架要求每个假说有「台词交锋」，50 秒装不下五轮问答；且「法庭」隐喻与档案美学重叠。*

**C. 双杯赛跑（过程直击）**
两只杯子并排赛跑，画面一半给比赛、一半给闪回解说，全程竞速节奏。
*优点：动感强。*
*缺点：把「未解之谜」拍成了「已知胜负的竞赛」，结尾落不到「悬案」上；两次冻结过程占满时长，没有科学史纵深。*

**选择：A。** 悬案结构让风格的每个原生招式（编号物证、前科卡、嫌疑人板、涂黑、盖章、归档）都有叙事岗位，且「无定论」这个科学事实恰好是档案美学的母题——档案柜里本来就该有未结的卷宗。

## 2. 一句话与弧线

**Logline**：一桩被老师嘲笑的学生提问，牵出横跨两千年的结冰悬案——科学查了六十年，档案至今不敢盖章。

**弧线**：钩子（热水先结冰，不可能？）→ 建立（一个学生因提问被嘲笑）→ 升级（历史上大人物都报过案；1969 年复现属实）→ 转折（五个嫌疑人全部说不清）→ 悬置（结论涂黑，盖章「未结案」）→ 回响（抽屉里全是同款卷宗：科学不怕悬案，就怕没人再问）。

**书挡**：开场「被嘲笑的提问」对上结尾「下一个提问的人，也许就是你」。

**事实底线**（成片另附 FACTS.md 含出处）：1963 年姆潘巴（坦桑尼亚）热冰淇淋液先冻、1969 年与 Osborne 合著 *Cool?*（Physics Education）、亚里士多德/培根/笛卡尔均有记载、五大假说均未获公认、复现有条件性。不用「一定」「证明」等绝对表述。

## 3. Benchmark（只学语法，不抄内容）

- **《猫鼠游戏》片头序列**（Kuntzel+Deygas）：学它的「文件在镜头间被翻动、盖章、归档」的节奏感——每个文件出场都伴随一声落实音效和一次干脆的位移，绝不软绵绵淡入。不学：它的角色插画造型、爵士配乐语汇、具体转场设计。
- **Lichtenstein 时代本戴点印刷品**（风格规范引用）：学「点径即明暗、套印偏移即阴影」的视觉逻辑在运动中的用法（点晕呼吸、边缘点聚集表紧张）。不学：任何具体构图与作品。

## 6. Cue map

拍速 **100 BPM**（1 拍 = 0.6 s，1 小节 = 2.4 s，4/4）。音色全部出自风格音色盘：合成 kick/snare/clap/hat、方波八分贝斯、三角波 pad、**马林巴质感 pluck**（基频+~4×泛音）、拨弦+指响（潜行）、**八音盒铃**（结尾）。

| 段落 | t (s) | 小节 | 情绪 | 配器 |
|---|---|---|---|---|
| OPEN | 0.0–5.5 | 1–2.3 | 悬 | 低 pad + 指响碎点 |
| EX1 陈述 | 5.5–11.5 | 2.3–4.8 | 朴实、受屈 | 马林巴主题 + 方波贝斯 8 分 |
| EX2 前科 | 11.5–17.5 | 4.8–7.3 | 潜行、翻旧账 | pizzicato + 指响，贝斯半音下行 |
| EX3 复现 | 17.5–24.0 | 7.3–10 | 立案、提速 | 全奏：kick/snare 进，马林巴高八度 |
| BOARD | 24.0–33.0 | 10–13.75 | 紧、压 | 剥离至贝斯+指响+hat，31.5s 起上滑 sweep |
| REDACT | 33.0–36.0 | 13.75–15 | 屏息 | 近静默，仅纸声与 click；**35.4–36.0 全静默** |
| STAMP | 36.0 | 15.0 | 落锤 | 盖章重击独立于音乐 |
| TAG | 36.0–50.0 | 15–20.8 | 释然、余味 | 八音盒琶音（D 大调分解）+ 软 pad，44s 抽屉 thump 入乐句 |

**落点校验目标**：字符 pop 逐个贴 8 分音符栅格；三次盖章（3.6 / 23.4 / 36.0）均在整拍上（第 6 / 39 / 60 拍）；钉卡声（12.5/14.5/16.5；24.6 起每 1.7s≈节拍近似）逐一对齐 0.1 s 内。用 cuecheck 脚本校验，目标 0 ms。

## 8. 字幕与标题设计

- **大标题**：Noto Serif SC 900，100–200 px，左对齐近页边，套印偏移阴影（+8/+8 px，cobalt，multiply）。逐字符 30–100 px 下落砸入，stagger 0.05 s。
- **展示数字/案号**：Bagel Fat One（CASE 号、巨型①②③、计时数字），允许出血出画。
- **字幕条（全片台词职责）**：深墨圆角胶囊 + cobalt 偏移阴影，纸色文字，**关键词用芥末黄高亮**；大标题弹出后 pop 入，停留 ≥ max(1.8 s, 逐字读速 + 0.6 s)（中文按 4.5 字/秒 + 1.5 s 校验）。
- **插入语气**：ZCOOL KuaiLe（老师气泡「你搞错了！」），纸面填充+粗墨描边+偏移阴影。
- **HUD/数据**：JetBrains Mono 800：左上「CASE 1963-MPE · 卷宗」章节芯片、右上 REC 红点+日期 1963/1969（暗色场景反色）。
- **盖章文字**：黑重 sans，双圆角矩形框，粗墨纹+位移滤镜，93% 不透明度，斜 ±10°。
- **字体加载**：全部 Google Fonts OFL，中文子集经 `&text=` API 按成片全部字符预下载到项目 `fonts/`，`font-display: block`，全字符覆盖校验（风格坑位 #9 第一条）。

## 9. 调色板（≤5 墨 + 纸）

米色纸面 cream（底）｜深墨蓝 navy（全部描边、正文字幕条、淡出色）｜钴蓝 cobalt（套印阴影/冷杯）｜芥末黄 mustard（高亮关键词/热杯/数字）｜朱红 vermilion（**只给**：盖章、REC 点、报警）。

## 10. 技术要点备忘

- 30 fps 渲染（`--fps 30`）；点阵 step ≥ 20 px 防 moiré；闪白封顶 0.5；dot wipe 最大半径盖满格对角线。
- 每个裁切半调数字独立 clip id；时间窗外元素显式 opacity 0。
- line boil（~10 fps 重播种，~5 px）只上角色与手绘道具，**绝不**上文字/点阵/字幕。
- `TEXTS(t)` 全量上报（含逐字砸入的完整文本），过 readcheck；EV 事件驱动 mix.py；timeline.js 单一事实源导出 JSON 给配乐/字幕/校验。
- 结尾 grep 无 LemoLab/Opus 字样；与 demo poster 并排比对（结构/开场/签名镜头/镜头路径/配乐形态/结尾至少 4 项不同——本片与 demo 的差异点：开场用物证袋夜地而非 demo 开场、前科板+涂黑+抽屉拉出均为 demo 未用结构、结尾非 stamp 判决而归档回响）。
